# Third-party assets

The Panel Right glyph is from Microsoft's [Fluent System Icons](https://github.com/microsoft/fluentui-system-icons), used under the MIT license. Copyright (c) Microsoft Corporation. The original SVG is in `Assets/FluentPanelRight.svg`; its license is included in `Assets/FluentSystemIcons-LICENSE.txt`.

The application adds a blue accent gradient and rasterizes this geometry at multiple icon sizes.

The included legacy Options and Alert glyphs are from the same Microsoft Fluent System Icons project. Their original SVGs are included as `Assets/FluentOptions.svg` and `Assets/FluentAlert.svg`, under the same MIT license.

The included legacy Start artwork renders the Windows 11 mark in blue. Windows and its logo are trademarks of Microsoft Corporation; this is an independent project.

The legacy taskbar-recovery helper uses [ManagedShell 0.0.374](https://github.com/cairoshell/ManagedShell), licensed under Apache-2.0. Its license is included in Assets/ManagedShell-LICENSE.txt. The WinUI interface is original to this project; the recovery helper uses WPF as required by ManagedShell and does not stay running in either sidebar mode.

The installer uses the [WiX UI dialog library 6.0.2](https://github.com/wixtoolset/wix/tree/v6.0.2/src/ext/UI), copyright .NET Foundation and contributors, under the Microsoft Reciprocal License. Its license is included in Assets/WixUI-LICENSE.txt. The custom options and review pages are part of this project's installer source.
