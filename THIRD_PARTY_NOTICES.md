# Third-party assets

The Panel Right glyph is from Microsoft's [Fluent System Icons](https://github.com/microsoft/fluentui-system-icons), used under the MIT license. Copyright (c) Microsoft Corporation. The original SVG is in `Assets/FluentPanelRight.svg`; its license is included in `Assets/FluentSystemIcons-LICENSE.txt`.

The application adds a blue accent gradient and rasterizes this geometry at multiple icon sizes.

Quick Settings and Notifications use the Options and Alert glyphs from the same Microsoft Fluent System Icons project. Their original SVGs are included as `Assets/FluentOptions.svg` and `Assets/FluentAlert.svg`, under the same MIT license.

The Start button renders the Windows 11 mark in blue. Windows and its logo are trademarks of Microsoft Corporation; this is an independent project.

Longhorn mode uses [ManagedShell 0.0.374](https://github.com/cairoshell/ManagedShell), licensed under Apache-2.0. Its license is included in Assets/ManagedShell-LICENSE.txt. The WinUI interface is original to this project; the separate shell-services helper uses WPF as required by ManagedShell.
