FluentSidebar 1.3.0 — preview

Longhorn mode now keeps the original Windows taskbar visible and intact. Start, running apps, the tray, clock, Quick Settings, notifications, and input switching stay on Windows' taskbar.

The rail's Start and Apps buttons, Quick Settings, Notifications, and Language Input Switcher have been removed. Longhorn mode now focuses on search, pinned launchers, and gadgets. Old taskbar-hiding and tray-clipping preferences are reset when the app starts. Taskbar recovery remains available for upgrades from an older version.

Neither sidebar mode keeps a shell helper running. Offscreen gadgets skip live refreshes, hidden auto-hide mode slows its timer, and slideshow updates stop when the card is offscreen. App icons use a memory cache capped at 96 entries. A visible second hand or active countdown still updates every second.

Rail search suggestions now include app icons and can extend outside the narrow rail. Quick Launch still lets you choose installed apps and websites. Clock customization and card appearance have distinct right-click commands.

The calendar keeps six weeks, the puzzle stays square, and card heights remain fixed. Settings follows the selected Light, Dark, or System theme with Acrylic or Mica.

This is an unsigned x64 preview. Existing notes and preferences are preserved. Multiple displays and modified taskbars need broader testing.
