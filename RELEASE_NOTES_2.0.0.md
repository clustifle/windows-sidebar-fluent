FluentSidebar 2.0.0

The app launcher now has a native icon grid, app-name search, a pinned-items view, and right-click pinning. Pinned websites also appear in search. Its Windows tab lists open application windows and lets you switch to them. This list refreshes when opened or when requested, without background polling.

The gadget gallery now has search, categories, descriptions, and an Added indicator. Select a gadget to show or hide it, or open the arrangement view to change its order. Existing card customization remains available from right-click menus.

Appearance and operating mode are separate settings. Choose Fluent, Vista, or Longhorn 4074, then choose Desktop Sidebar or Launcher. Launcher mode adds an Apps entry and search without taking over the Windows taskbar. Existing users keep their sidebar mode and settings.

This build retains the nature puzzle samples, completion animation, provider thumbnails in feed headlines, and the full setup wizard from 1.3.4.

Scope: this is a desktop launcher release. It does not yet replace the Windows sign-in shell, provide a replacement desktop/tray host, or host original Vista `.gadget` packages. Those parts of the broader shell outline remain unimplemented and are not exposed as working modes. Explorer continues to provide the desktop, taskbar, Start, tray, notifications, and system panels.
